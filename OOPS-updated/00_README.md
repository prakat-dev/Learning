# ABAP OOP — Complete Notes Set

> Day 1, Topic 1 of the 5-Day SAP ABAP Learning Plan. Balanced notes plus complete, compiling code examples. Modern ABAP (7.4 / 7.5+) aware.

## How to use

Each file is self-contained. Read top to bottom for a full pass, or jump to one topic. Every file ends with a **Quick self-test** — cover the answers and quiz yourself.

## Contents

### Tier 1 — Basic (Foundation)
- **01 — Classes & Objects** — definition/implementation, visibility, class categories, instance vs static, constructors, destructor, `me->`
- **02 — The Four Pillars** — encapsulation, abstraction, inheritance, polymorphism, each with a complete example

### Tier 2 — Intermediate
- **03 — Inheritance & Polymorphism** — `super->`, redefinition, abstract/final, casting, runtime polymorphism
- **04 — Interfaces** — multiple interfaces, aliases, constants, composition, the BADI link
- **05 — Events** — raise/handle, `SET HANDLER`, static vs instance, observer pattern
- **06 — Exception Handling** — exception hierarchy, TRY/CATCH/CLEANUP, a full custom exception class, resumable exceptions

### Tier 3 — Advanced
- **07 — Design Patterns** — singleton, factory, strategy, template method, observer, MVC, dependency injection
- **08 — Modern ABAP Syntax** — inline declarations, NEW/VALUE/CONV/CORRESPONDING/COND/SWITCH/REDUCE/FILTER/FOR, table expressions, string templates
- **09 — ABAP Unit Testing** — ABAP Unit, assertions, the Test Double Framework, mocking, injection
- **10 — Advanced Topics** — friendship, persistence classes (with full CRUD example), shared objects, OOP ALV (CL_SALV_TABLE)
- **11 — Clean ABAP & Best Practices** — SOLID, naming, pitfalls, Clean Core / ABAP Cloud readiness

## Suggested study order

Work through Basic → Intermediate → Advanced in number order. Short on time before an interview? Prioritize 02, 03, 04, 06, then skim 07 and 09.
